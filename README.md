# Umarex VPN

## Project Description
Umarex VPN is a versatile VPN service that supports multiple protocols, including VLESS and VMess, allowing you to enjoy a secure and private browsing experience.

## Features
- Support for VLESS and VMess configurations
- High-speed servers
- User-friendly interface
- Easy setup and configuration
- Strong encryption for enhanced privacy

## Installation Instructions
1. **Clone the repository**:
   ```bash
   git clone https://github.com/larega6-sketch/umarex-vpn.git
   ```
2. **Navigate into the project directory**:
   ```bash
   cd umarex-vpn
   ```
3. **Install the required dependencies**:
   ```bash
   npm install
   ```

## How to Use VLESS and VMess Configs
### VLESS Config
1. Open your VPN client.
2. Choose the VLESS protocol.
3. Input the server details and your user ID.
4. Connect and enjoy the secure connection.

### VMess Config
1. Open your VPN client.
2. Select the VMess protocol.
3. Input the server address, port, UUID, and network type.
4. Click connect and start browsing securely.
